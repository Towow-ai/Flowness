# Security policy

## Supported versions

No public Flowness version is supported yet. The current tree is an Open Alpha
candidate. A release will add the supported-version table and response targets.

## Reporting a vulnerability

Do not publish a suspected vulnerability, credential, personal record, customer
artifact, or server detail in a public issue. Once the public repository exists,
use its private GitHub Security Advisory reporting flow. Until that flow is
enabled, keep the report private and wait for the release owner to publish the
authenticated security contact; this file deliberately does not invent one.

Include the affected version or commit, reproduction steps, observed impact, and
whether any secret or personal data may have been exposed. Do not access data or
systems beyond what is needed to demonstrate the issue.

The absence of a public contact is a release blocker, not permission to disclose
sensitive details publicly.
