# 留给后来者 / Deposit for the Future

（占位卷——魂已就位，待第一个真实沉淀样例出现时填实。）

## 这个读者

对面是**未来的某个陌生人**——可能是另一个 agent、也可能是几个月后的你自己。它没有你此刻的上下文，也不知道你当时在想什么。

## 主要漂移

**写给现在的自己。** 沉淀（写 SKILL.md、概念图、经验手册）最容易翻的车，就是为留存而倒一大坨、不分层——结果是一片沼泽（比如一份没层级的大文件），等于让后来人"自己去翻"。

## 魂怎么应用

- **分层、渐进披露**：最该先看见的在最前、一句话能用；细节往下沉、按需展开。这正是这个 skill 自己的结构（魂在 SKILL.md，精细度在分卷）——沉淀要做到它自己做的事。
- 写给陌生人，不写给"记得来龙去脉的自己"：每个非常识的概念，配一个它在一米内就能抓住的锚。
- 把你**想过的结果**呈现成概念图，让后来人不必重走一遍你的思考——但别把你的全部思考过程倒进去。

## 真样例 · 重写 fix/SKILL.md（2026-06-30）

第一个真实沉淀样例：重写 fix 这份持久人格手册。SKILL.md 正是"留给后来者"的典型——每个新 fix worker 一生只读它一次。

**✗ 改前**（旧 11KB）：开头"我是 M-1.6 fix skill 的 main session"（用内部编号自我介绍）；满屏后来人查不动的代号（§3.5 / F-09a / T-L1-72 / RUN-039 / V-02）；整段"落地现状（T-L1-72…RUN-039 resolved）"是实现历史流水账、对干活零用；8 个失败模式用英文黑话名。后来者附身上来，得的是"强大的错"——能量足、却被代号和流水账带偏了瞄准。

**✓ 改后**（plain + 分层）：第一句就是目标（"把一条被发现的问题修干净——修一个不制造下一个"）；往下分层——干净闭合长什么样 → 8 个失败模式（中文名 + 一句症状）→ 权力边界 → 落账收尾；代号清零（语义一条没丢）、流水账删成它真正要表达的一句、失败模式中文命名。最值钱的那个 createBatch 干净/莽撞闭合例子留在最前。

变化正是这一卷的魂：分层渐进披露、写给陌生人不写给"记得来龙去脉的自己"、每个非常识词就地落地。

**代理尺**：把改后丢给一个陌生 fix worker，问"开工前一米内，你能不能一句话说出'干净的闭合长什么样'、并找到那 4 条自检尺？"——找得到 = 分层对了；还要翻、还要问 = 沼泽没清干净。
