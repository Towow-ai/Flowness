# Flowness Media Kit

## Project name

**Flowness**

Pronunciation: “flow-ness.” Do not stylize the letters with `1` or use “F1ow.”

## Category

**Flow Engineering** — the engineering of work in motion.

## One-line description

**Flowness is a work-centered runtime for agentic software engineering. Work persists; agents, context, and graphs assemble around it.**

## Chinese description

**Flowness 是一个以工作为中心的 Agent 软件工程运行时：工作持续存在，Agent、上下文与 Graph 围绕它当前的状态动态形成。**

## 50-word description

Flowness keeps software work alive across changing agents, sessions, contexts, and plans. It projects current work state, compiles the next execution, supports governed reflow after failures or changed assumptions, and separates artifacts, activation, evidence, and owner acceptance. The current Open Alpha includes a reproducible assurance kernel and a larger inspectable mechanism set.

## Approved summary of current status

> The public Open Alpha ships a deterministic assurance kernel for isolated production, independent review, targeted rework, and fresh acceptance. A broader set of Flow-runtime mechanisms is public and inspectable, with additional paths used in dogfood or still under design. The project does not yet claim a complete public organic end-to-end Flow or comparative superiority.

## Logos and visual identity

Preferred symbol direction:

- a stable central Work seed or rounded square;
- execution modules forming and dissolving around it;
- a thin outer constitutional boundary;
- graph versions shown as faint successive paths;
- no robot face, brain, neon swarm, or permanent giant DAG.

Preferred visual tone:

- warm off-white background;
- ink/navy text;
- muted mineral and botanical accents;
- precise geometry with a slight hand-drawn human trace;
- generous whitespace;
- readable diagrams before decorative art.
